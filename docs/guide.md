# Spam Protection Bot — 使用指南

本文件同時提供繁體中文與簡體中文版本，內容一致。使用本機器人前，請一併閱讀[使用規範／Terms of Use](./index.html)。

## 繁體中文

### 1. 這是什麼

Spam Protection Bot（SPB，機器人帳號 [@WikiBlacklistRobot](https://t.me/WikiBlacklistRobot)）是一個由志願者營運、免費提供給 Telegram 群組使用的反垃圾訊息機器人。它會自動評估訊息與帳號特徵，刪除判定為垃圾訊息的內容並封禁來源帳號，同時提供一整套讓群組管理員手動處理可疑內容的指令。

### 2. 如何加入群組

把機器人加入群組後，請授予至少以下兩項管理員權限，否則部分或全部功能無法運作：

- **刪除訊息**
- **封禁用戶**

機器人加入群組時會自動發送使用規範連結；只要繼續使用本機器人，即代表群組管理團隊與所有使用者同意該規範。

**私密（非公開）群組請勿使用本服務。** 私密群組不是垃圾訊息散布的對象，本項目基於資源管理考量不對私密群組提供服務，詳見[使用規範第 3 條](./index.html#eligibility)。

### 3. 所有人都能用的指令

| 指令 | 說明 |
| :--- | :--- |
| `/spam`（回覆可疑訊息） | 提交舉報，交由項目組人工審核 |
| `/case <案例ID>` | 查詢某次封禁的詳細記錄 |
| `/id` | 取得自己的 Telegram User ID |

舉報如果連續 3 次被判定為不成立，該帳號會暫時無法再使用 `/spam`，避免濫用舉報功能騷擾其他人。

### 4. 群組管理員指令

| 指令 | 說明 |
| :--- | :--- |
| `/sb`（回覆訊息） | 刪除該訊息並封禁發送者 |
| `/mute`（回覆訊息） | 禁言發送者 |
| `/kick`（回覆訊息） | 將發送者踢出群組（可再加入） |
| `/unban` `/unmute` | 解除封禁／禁言（僅對本群生效） |
| `/white` `/unwhite` | 加入／移除本群白名單；加上 `-global` 為全域白名單 |
| `/module` | 查看本群各防護模組的開關狀態 |
| `/module <名稱> on\|off` | 切換單一模組 |
| `/module all on\|off` | 一次全開或全關（基礎防護不受影響，見下） |
| `/warn [原因]`（回覆訊息） | 發出一次警告，達門檻自動處置（預設 2 次，見下） |
| `/unwarn [n]`（回覆用戶） | 移除最近 n 次警告，預設 1 |
| `/warns`（回覆或提供 user_id） | 查詢目前警告次數與紀錄 |
| `/warnconfig [門檻] [mute\|kick\|ban] [時長]` | 查看或設定本群警告門檻與處置方式 |
| `/ot`（回覆離題訊息） | 刪除該訊息並加警告（預設 1 次，可用 `/ot_warns` 調整） |
| `/ot_template <文字>` | 自訂 `/ot` 的提及訊息（`{user}`／`{count}` 佔位符） |

警告永不過期，只能用 `/unwarn` 手動移除。

### 5. 各防護模組

**預設開啟（基礎防護，不會被 `/module all off` 關閉）**

- **Flood**：短時間內連續洗版會被自動禁言。
- **GuestBan**：封禁透過 Telegram「訪客模式」（未加入本群卻能直接發文）發送廣告的機器人帳號，以及召喚該機器人的使用者。

**需自行開啟**

- **NoHalal**：偵測帳號名稱／簡介中常見的清真相關詐騙／廣告特徵。
- **NoSM**：自動刪除「加入群組」「退出群組」「置頂訊息」等系統訊息，讓聊天畫面更乾淨。
- **Captcha**：新成員入群後需回答一道簡單算式才能發言，逾時未答會被移出群組。
- **Netban**：訂閱本項目的跨群組共用黑名單（詳見下一節）。
- **CmdClean**：24 小時內重複嘗試使用無權限的指令，會被暫時禁言。
- **NoContact**：禁止在群組中分享聯絡人卡片。
- **NoVoice**：禁止傳送語音訊息。
- **NoExec**：禁止傳送可執行檔案（`.exe`、`.apk`、`.msi` 等）。

### 6. 封禁代號一覽

在日誌頻道或 `/case` 查詢結果中，封禁原因常以代號顯示，意義如下：

| 代號 | 意義 |
| :--- | :--- |
| `ML` | 機器學習模型判定為垃圾訊息 |
| `REGEX` | 觸發項目組設定的正則規則 |
| `ARABIC` | 偵測到清真相關詐騙特徵（NoHalal） |
| `FLOOD` | 洗版偵測（短時間內連續發送過多訊息） |
| `PERM_REPEAT` | 24 小時內重複嘗試使用無權限指令 |
| `GUEST_MODE` | 訪客模式機器人廣告（未加入本群卻發文） |
| `GUEST_MODE_INVOKER` | 召喚上述訪客模式機器人的使用者 |
| `CONTACT` | 分享聯絡人卡片（NoContact） |
| `VOICE` | 傳送語音訊息（NoVoice） |
| `EXEC_FILE` | 傳送可執行檔案（NoExec） |
| `BOTSPAM` | 純粹提及機器人帳號的訪客模式廣告 |
| `WARN` | 累計警告達本群設定的門檻，自動處置 |
| `PB` | 項目層級封禁（Project Ban），對所有群組強制生效，本群無法解除 |

### 7. Netban（跨群組共用黑名單）怎麼運作

開啟 Netban 模組的群組，會自動同步並執行本項目累積的共用黑名單——一旦某帳號被列入，之後在任何已開啟 Netban 的群組中出現都會被自動封禁，不需要各群組重新判斷一次。是否接收由每個群組自行決定，關閉即不受影響。

**會被列入共用黑名單的情況：**
- 機器學習模型判定為垃圾訊息，且分數達到項目全域門檻的自動封禁
- 訪客模式廣告機器人及其召喚者
- 經項目組人工審核通過的 `/spam` 舉報
- 純粹提及機器人帳號的廣告（`BOTSPAM`）

**不會被列入的情況：**
- 群組管理員手動使用 `/sb`（除非同時符合 `BOTSPAM` 的情形）
- `/mute`、`/kick`
- 洗版禁言（`FLOOD`）、指令濫用禁言（`PERM_REPEAT`）
- NoContact／NoVoice／NoExec 的附件類封禁

換句話說，共用黑名單只收錄「證據明確、跨群組共用風險高」的封禁，一般管理員手動處置與行為性禁言不會外溢到其他群組。

### 8. 我被封禁了，怎麼辦

1. 用 `/id` 取得自己的 User ID。
2. 到 [@SpamProtectionLogging](https://t.me/SpamProtectionLogging) 搜尋該 ID，找到對應的封禁紀錄與原因。
3. 如認為封禁有誤，透過 [@SEELE_01_BOT](https://t.me/SEELE_01_BOT) 提出申訴——這是唯一受理管道，其他方式提出的申訴不會被處理。

### 9. 隱私與資料

機器人會讀取群組訊息以判斷是否為垃圾訊息；被判定為垃圾訊息或經人工審核的內容可能被保留用於改進模型。詳細規定請見[使用規範第 5 條](./index.html)。請勿在啟用本機器人的群組中傳送敏感個人資料。

### 10. 意見回饋與交流

- 交流群：[@SpamProtectionChat](https://t.me/SpamProtectionChat)
- 日誌頻道：[@SpamProtectionLogging](https://t.me/SpamProtectionLogging)

### 7. Netban（跨群组共享黑名单）如何运作

开启 Netban 模块的群组，会自动同步并执行本项目累积的共享黑名单——一旦某账号被列入，之后在任何已开启 Netban 的群组中出现都会被自动封禁，不需要各群组重新判断一次。是否接收由每个群组自行决定，关闭即不受影响。

**会被列入共享黑名单的情况：**
- 机器学习模型判定为垃圾消息，且分数达到项目全局阈值的自动封禁
- 访客模式广告机器人及其召唤者
- 经项目组人工审核通过的 `/spam` 举报
- 纯粹提及机器人账号的广告（`BOTSPAM`）

**不会被列入的情况：**
- 群组管理员手动使用 `/sb`（除非同时符合 `BOTSPAM` 的情形）
- `/mute`、`/kick`
- 刷屏禁言（`FLOOD`）、指令滥用禁言（`PERM_REPEAT`）
- NoContact／NoVoice／NoExec 的附件类封禁

换句话说，共享黑名单只收录「证据明确、跨群组共享风险高」的封禁，普通管理员手动处置与行为性禁言不会外溢到其他群组。

### 8. 我被封禁了，怎么办

1. 用 `/id` 获取自己的 User ID。
2. 到 [@SpamProtectionLogging](https://t.me/SpamProtectionLogging) 搜索该 ID，找到对应的封禁记录与原因。
3. 如认为封禁有误，通过 [@SEELE_01_BOT](https://t.me/SEELE_01_BOT) 提出申诉——这是唯一受理渠道，其他方式提出的申诉不会被处理。
